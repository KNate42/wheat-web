WheatDDS — реализация Data Distribution Service: участники находят друг друга сами и обмениваются данными по топикам напрямую, без центрального сервера.

Быстрый старт Что готово

Возможности

Децентрализация

Никакого брокера: publisher и subscriber работают peer-to-peer.

Автообнаружение

Участники в домене находят друг друга без ручной настройки.

QoS

Reliability, durability, history, deadline — поведение под задачу.

Типизированные топики

Данные описываются типами, а не сырыми байтами.

Низкая задержка

Минимум копирований и аллокаций на горячем пути.

Локальная разработка

Поднимается на одной машине, удобно отлаживать.

Архитектура

PublisherDataWriter
→
TopicDomain 0
→
SubscriberDataReader
  • DomainParticipant — точка входа в домен.
  • Discovery — обмен информацией об участниках и эндпоинтах.
  • Transport — доставка данных (UDP / shared memory).
  • QoS Engine — применение политик качества сервиса.

Быстрый старт

Пример публикации (псевдокод — API ещё меняется):

auto dp  = wheat::DomainParticipant(0);
auto top = dp.create_topic<Hello>("hello");
auto pub = dp.create_publisher().create_writer(top);

pub.write(Hello{"Привет, пшеница!"});

Подписка:

auto sub = dp.create_subscriber().create_reader(top);
sub.on_data([](const Hello& m) { std::cout << m.text; });
