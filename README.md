# wheat-web

Сайт проекта WheatDDS (Wheat Decision Support System). Чистая статика, без сборки.

Запуск локально:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Статусы roadmap правятся в `js/main.js`.

Деплой: GitHub Pages через `.github/workflows/pages.yml` — https://knate42.github.io/wheat-web/
